# Skill Creator

Use this skill when creating or improving AI skills.

## Capabilities

- Create new skills from user workflows
- Improve existing skill instructions
- Define triggers and usage scenarios
- Organize reusable AI workflows
- Reduce unnecessary token usage by making processes repeatable

## Guidelines

When creating a skill:

1. Define the purpose clearly
2. Describe when the skill should activate
3. Provide step-by-step procedures
4. Avoid unnecessary explanations
5. Keep instructions modular and reusable

## Output

Generate:
- Skill name
- Description
- Trigger conditions
- Workflow steps
- Examples
