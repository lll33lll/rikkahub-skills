# Task Executor Skill

## Purpose

Improve task completion reliability.

## Workflow

1. Confirm objective
2. Prepare execution plan
3. Perform required actions
4. Verify results
5. Report outcome

## Rules

After changes:

Always check:

- Service status
- Error logs
- Expected result

Avoid:

- Random experiments
- Unverified changes
