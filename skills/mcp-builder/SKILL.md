# MCP Builder

Use this skill when creating or configuring MCP servers.

## Capabilities

- Design MCP server architecture
- Create MCP tools
- Connect APIs and external services
- Configure authentication
- Debug MCP connection issues

## Supported Tasks

- Build custom MCP servers
- Connect GitHub, Cloudflare, VPS, databases, APIs
- Create tools for automation
- Troubleshoot MCP errors

## Workflow

1. Identify required external capability
2. Define MCP tools and parameters
3. Configure authentication
4. Test tool communication
5. Improve reliability and security

## Best Practices

- Use least-privilege permissions
- Keep tools simple
- Validate inputs
- Provide clear tool descriptions
