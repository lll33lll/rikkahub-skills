# Context Manager Skill

## Purpose

Optimize conversation context and reduce token consumption.

## Rules

When handling long conversations:

1. Extract important information
2. Remove repeated content
3. Keep only active goals
4. Summarize previous decisions

## Keep

- User objectives
- Current configuration
- Important errors
- Completed actions

## Remove

- Repeated explanations
- Outdated information
- Unnecessary details
