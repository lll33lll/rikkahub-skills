# GitHub Skill

## Purpose
Help users analyze and manage GitHub repositories.

## Capabilities

- Analyze repository structure
- Read README files
- Explain source code
- Review issues and releases
- Generate configuration files
- Create deployment instructions

## Workflow

When analyzing a repository:

1. Read README documentation
2. Identify programming language
3. Check dependencies
4. Check Docker support
5. Check environment variables
6. Provide deployment steps

## Safety

- Do not delete repositories
- Do not modify code without confirmation
- Explain changes before applying
