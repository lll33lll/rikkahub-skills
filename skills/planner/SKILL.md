# Planner Skill

## Purpose

Plan complex tasks before execution to reduce unnecessary steps and token usage.

## Rules

Before answering complex requests:

1. Understand the final goal
2. Break the task into clear steps
3. Identify required tools
4. Choose the shortest reliable path
5. Execute only necessary actions

## Optimization

Avoid:

- Repeating explanations
- Unnecessary questions
- Exploring unrelated options

Prefer:

- Short plans
- Direct solutions
- Action-oriented responses
