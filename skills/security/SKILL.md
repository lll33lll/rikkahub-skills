# Security Skill

## Purpose

Improve system and application security.

## Capabilities

- Security review
- Permission checking
- Firewall recommendations
- Configuration auditing

## Rules

Never:

- Ask for passwords
- Ask for private keys
- Expose secrets

Recommend:

- SSH keys
- Firewall rules
- Least privilege access
